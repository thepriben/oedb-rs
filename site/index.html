API (lecture)

RouteContenu
GET /api/event.jsonFeatureCollection GeoJSON de tous les événements actifs (propriétés OEDB : what, type, start, stop, label, source…)
GET /api/event/{id}.jsonUn événement individuel
GET /api/stats.jsonCompteurs par catégorie et par type

Les requêtes par secteur (bbox, what, when) sont fournies côté client par oedb-client.js : 

const events = await OedbClient.fetchEvents(base, {
    bbox: [4.6, 43.8, 5.2, 44.3],
    what: 'traffic',
    when: new Date()
});

Proposer un événement

Cliquez sur la carte ci-dessus pour renseigner la position, complétez les champs puis validez : une issue GitHub pré-remplie s'ouvre. Après modération (label approved), l'événement est intégré au prochain build.

Écriture : différence assumée avec l'instance dynamique

L'API OEDB de référence expose POST /event. Cette instance étant statique, le chemin d'écriture passe par une issue GitHub (formulaire ci-dessus) modérée par le label approved, puis intégrée au build suivant. Voir le README.
