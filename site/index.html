oedb-rs — événements du Vaucluse (FR-84)

Instance OpenEventDatabase statique, générée en Rust et servie par GitHub Pages. Événements routiers Bison Futé (filtrés sur la limite réelle du département) et événements culturels curés, avec liaison Wikidata optionnelle.

API (lecture)

RouteContenu
GET /api/event.jsonFeatureCollection GeoJSON des événements actifs (propriétés OEDB : what, type, start, stop, label, source — plus, si renseignés, wikidata, type_wikidata, place_wikidata)
GET /api/event/{id}.jsonUn événement individuel
GET /api/stats.jsonCompteurs par catégorie et par type

Requêtes par secteur (bbox, what, when) côté client via oedb-client.js. Les événements partageant un même point sont légèrement étalés (~25 m) et regroupés en grappes au dézoom.

Proposer un événement

Cliquez sur la carte pour renseigner la position. Les champs Wikidata sont optionnels : recherchez par libellé (autocomplétion) ou laissez vide — tout fonctionne sans. La validation crée une issue GitHub pré-remplie, intégrée au prochain build après modération (label approved).

Écriture : différence assumée avec l'instance dynamique

L'API OEDB de référence expose POST /event. Cette instance étant statique, l'écriture passe par une issue GitHub modérée (label approved), intégrée au build suivant. Voir le README.
